# Software implementation

## Core
The methodology is implemented in the `R` package `hce`. For example, to calculate success (win) odds, use the function `calcWO()`. Thresholds are implemented via the function `deltaWO()`. The package is well documented. Maraca plots are provided in the `maraca` package, which is also well documented.

## Other

- **Data manipulation:** `dplyr`,  `tidyr`
- **Visualization:** `ggplot2`, `patchwork`
- **Parallel Computing:** `furrr`
